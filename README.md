The Daily Globe: a Python 3.13 program that draws a one-page newspaper front page summing up Wednesday 25 November 2026 in five checked stories — the Shenzhou-24 launch carrying the first foreign astronaut to Tiangong, the Australia–Solomon Islands treaty signed in Canberra, the breach of the CIA and ODNI unclassified systems, Putin's talks with the Sultan of Brunei in Moscow, and the US Army's controlled detonation of four tonnes of unstable explosive in Iowa — and writes it as a 1024×1024 PNG. Pure standard library: a small software rasterizer with a hand-built 5x7 bitmap font, no network, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
